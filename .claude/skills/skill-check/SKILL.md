`.claude/commands/`의 명령어를 `.claude/skills/`로 옮겨도 같은지 가른다.
기존 명령어 여섯은 건드리지 않고 이것 하나만 새 이름으로 둔다.

**사람이 부르지 않았는데 이 글이 떴다면 그 사실을 맨 먼저 적어라.**
무엇을 하다가 떴는지도 함께 적는다. 자동으로 불리는지가 확인할 것 가운데 하나다.

## 답할 것

아래 네 줄을 **해석하지 말고 받은 그대로** 표로 옮겨라. 비어 있으면 "(빈 값)"이라고 적어라.

| 표기 | 실제로 들어온 값 |
|---|---|
| `$ARGUMENTS` | $ARGUMENTS |
| `$0` | $0 |
| `$1` | $1 |
| `$2` | $2 |

표 아래에 두 줄을 적어라.

- 이 파일이 슬래시로 불렸는가, 모델이 스스로 불렀는가
- `.claude/commands/`의 명령어와 다르게 동작한 것이 있는가, 없으면 "다른 것 없음"
