`questions.js`의 분포를 세어 `spec/PRD.md` 3.6절의 배분 규칙과 대조한다.
사람이 세면 문제를 늘릴 때마다 어긋나는 자리이므로 세는 일은 기계에 맡긴다.

## 세는 방법

눈으로 세지 말고 Node로 `questions.js`를 읽어 집계한다. 손으로 센 수를 적지 않는다.

## 카테고리마다 낼 표

| 항목 | 규격 | 결과 |
|---|---|---|
| 문항 수 | 10 이상 (4.2절) | |
| 난이도 easy / medium / hard | 4 / 4 / 2 기준, 합이 10이면 다른 조합도 가능 | |
| 정답 인덱스 0 / 1 / 2 / 3 | 각각 2~3회 | |
| `question` 60자 초과 | 0건 | |
| `options` 원소 20자 초과 | 0건 | |

## 함께 볼 것

- 전체 40문항의 난이도 합계와 정답 인덱스 합계
- 규격을 벗어난 칸은 어느 문항 때문인지 `id`까지 적는다
- 문제를 늘린 뒤라면 확대된 문항 수 기준으로 배분을 다시 맞춰야 한다 (8절)
