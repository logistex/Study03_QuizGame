## 4. 배포 후 스모크 테스트

프로덕션 주소에서 네 화면을 실제로 지났음.

| 화면 | 확인한 것 |
|---|---|
| 시작 | 카테고리 넷과 문항 수, 이름 입력 |
| 퀴즈 진행 | 열 문항, 고르는 즉시 정답 여부와 해설 |
| 결과 | 10/10, 순위표 1위 진입 |
| 순위표 | 카테고리별 넷과 전 범위, 한 행 |

콘솔 오류 없음. 파일 넷이 모두 HTTP 200으로 왔음.

**이 시점의 화면을 나중에 다시 여는 주소가 있음.** 배포마다 따로 붙는 주소이며, 대표 주소와 달리 그 배포를 계속 가리킴.

| 주소 | 무엇 | 로그인 없이 |
|---|---|---|
| `quiz-game-gamma-bay.vercel.app` | 대표 주소. 늘 최신 배포 | 200 |
| `quiz-game-mh8hcfy21-bdmp1.vercel.app` | 배포 `mh8hcfy21` 자체 | 302로 로그인 화면 |

지금은 대표 주소가 그 배포를 가리켜 둘이 같은 화면임. 구현 2단계에서 새 배포가 생기면 갈림.

**팀 밖의 사람은 뒤엣것을 열 수 없음.** 자기 팀에 로그인해야 열리며, 로그인하지 않은 요청은 Vercel 로그인 화면으로 감. 노트를 읽는 사람에게는 안 열린다는 뜻임.

## 6. 이월한 항목 하나

체크리스트 넷째의 뒷부분임.

| 부분 | 결과 |
|---|---|
| DB 프로젝트가 둘 | 통과. 둘 다 `ACTIVE_HEALTHY` |
| 환경 변수 여섯이 Preview 셋, Production 셋 | 통과 |
| 그 값이 어느 프로젝트를 가리키는가 | 확인할 수 없음 |

값 여섯이 Vercel에 **민감 항목으로 저장돼 있음.** `vercel env pull`이 값 자리에 `[SENSITIVE]` 문자열을 내려 줌. 넣은 사람 말고는 읽을 수 없고, 다시 넣는 것만 됨.

계획서가 이 항목에 「연결을 확인하는 것은 서버 함수가 생기는 구현 2단계다」를 붙여 두었으므로, 구현 2단계 체크리스트의 프리뷰 저장 확인이 이 항목의 판정을 대신함.

**대시보드 화면에서도 값이 안 보임.** 처음에는 CLI로만 확인해 화면을 보지 못했으나, 2026년 8월 30일에 로그인된 브라우저로 환경 변수 화면을 열어 확인했음. 목록에 이름과 환경과 추가일만 나오고 값 자리가 아예 없음.

| 이름 | 환경 |
|---|---|
| `SUPABASE_URL` | Preview, Production |
| `SUPABASE_PUBLISHABLE_KEY` | Preview, Production |
| `SUPABASE_SECRET_KEY` | Preview, Production |

**그래서 이 항목의 앞 두 부분은 화면으로 확인됐음.** 여섯이 Preview 셋과 Production 셋으로 갈려 있음. 남은 것은 셋째 부분뿐이며, 그 값이 어느 프로젝트를 가리키는지는 여전히 서버 함수가 생기는 구현 2단계에서 판정함.

## 7. 판정 과정에서 걸린 것

### 7.1 Vercel CLI 계정이 갈렸음

CLI가 `logistex`로 로그인돼 있었고 그 계정에 `bdmp1` 팀이 없어 `quiz-game`이 보이지 않았음. 장치 승인으로 `haewoong007`으로 바꾼 뒤에 모두 풀렸음.

**학생에게는 이 절차가 필요 없음.** 계정이 하나라 브라우저가 이미 로그인돼 있고 승인은 한 번임. 노트에 넣지 않기로 했음.

### 7.2 권한 분류기가 막은 것

키를 받는 명령과 환경 변수를 내려받는 명령이 처음에 막혔음. 신 교수의 허용을 받고 다시 돌렸음.

한 건은 분류기 탓이 아니었음. `supabase inspect db`에 `timeout`을 앞에 붙였다가 막혔는데, 떼고 돌리니 그대로 됐음. **막힌 이유를 명령 전체가 아니라 어느 조각인지까지 좁혀야 함.**

### 7.3 앞 세션이 같은 항목에서 네 번 멈췄음

74번이 표로 남긴 것을 이번에 기록으로 확인했음. 같은 요청문을 네 번 받았고 네 번 다 환경 변수 항목을 판정하지 못한 채 넘겼음.

| 회차 | 그 항목을 뭐라 냈나 |
|---|---|
| 1 | 확인 불가 |
| 2 | 아직 안 봤음 |
| 3 | 미확인 |
| 4 | 확인 못 함 |

이번에는 요청문을 받기 전에 접근 수단을 먼저 확인하고, 막히는 지점을 미리 여쭈어 풀었음. **판정에 필요한 것을 답을 쓰는 도중에 찾지 않는 것이 갈림길이었음.**
