## 3. Anthropic API 키가 없어 문항 생성을 앱 밖으로 옮김

`.env`에 넣으신 키 둘이 `api.anthropic.com`에서 401로 거절됐음. 32자이고 `sk-ant-api03-`로 시작하지 않아 Anthropic API 키가 아니었음. **Claude Pro 구독으로는 API 키가 나오지 않고 Console 계정과 별도 결제가 필요함.**

학생마다 유료 키를 발급받게 할 수 없어 **생성과 판정을 앱 밖으로 옮겼음.**

```
선생님이 클로드 데스크톱에 문항 생성을 요청
  → 클로드가 문항을 만듦
  → 다른 세션이 문항 규칙 여덟을 판정함
  → 선생님이 등록을 요청하면 클로드가 api/authoring.js를 부름
  → 서버 함수가 데이터 검사 열셋을 돌리고 생성 요청 테이블에 이력을 남김
  → 검사를 통과한 것만 보이고, 채택한 것만 문항 테이블에 들어감
```

**뜻밖의 이득이 하나 있음.** 판정이 앱 밖으로 나가면서 「앱 안에는 세션이 없어 판정을 한 번만 돌린다」던 완화가 되돌려졌음. 1차 계획서 1.8절의 「서로 다른 세션 둘」을 그대로 쓸 수 있음.

**서버 함수가 요청자를 확인하는 방법도 정했음.** 브라우저는 로그인 토큰으로, 클로드는 **비밀 키를 헤더로 보내는 관리 경로**로 들어옴. 그 경로를 브라우저에 열지 않음. 이것은 인증이 아니라 「비밀 키를 쥔 쪽을 앱 주인으로 믿는 것」이며, 키를 쥔 쪽은 서버 함수를 건너뛸 수도 있으므로 방벽이 아니라 편의임.
