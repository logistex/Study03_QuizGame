# PRD 2차 개정 — 프롬프트를 설계하고 실행한다

- 쓴 세션: 53번, 55번을 쓴 세션과 같다
- 쓴 프롬프트는 [`archive/prompts/prd-phase2-prompt.md`](../../archive/prompts/prd-phase2-prompt.md)에 있다
- 개정 전 판본은 [`archive/PRD-v5.md`](../../archive/PRD-v5.md)로 떴다

## 1. 프롬프트를 어떻게 설계했나

**PRD를 고쳐 달라고만 하지 않았다.** 무엇을 근거로 어느 절을 어떻게 고칠지를 지정했다. 넣은 것이 여섯이다.

| 부분 | 까닭 |
|---|---|
| 근거 문서를 가리킴 | 대화 기억에 기대면 세션이 바뀔 때 재현되지 않는다 |
| 고칠 절을 번호로 지정 | "2차에 맞게 고쳐 줘"만 주면 어디까지 손댈지가 매번 달라진다 |
| 고치지 말 것을 따로 적음 | 규격 동결이 끝났다고 해서 전부 열린 것이 아니다 |
| 보존을 1번 절차에 둠 | 고친 뒤에 뜨면 이미 늦다 |
| 목록을 먼저 보이게 함 | 잘못 읽은 것은 고친 뒤보다 고치기 전에 잡는 편이 싸다 |
| 멈출 조건을 적음 | 추측으로 채운 문장이 나중에 다른 결정의 근거가 된다 |

**핵심은 추측 금지다.** 규격 문서에 근거 없는 문장이 들어가면 나중에 그 문장을 근거로 또 다른 결정을 하게 된다.

## 2. 절차를 하나 건너뛰었다

**프롬프트 2번 "목록을 먼저 보이고 확인을 받는다"를 밟지 못했다.** 사용자가 자리를 비운 상태에서 최대한 진행하라는 요청을 받아 확인 없이 고쳤다.

- 개정 목록은 아래 3절에 있다. **확인은 사후가 되었다**
- 잘못 읽은 자리가 있으면 되돌리는 것은 `git revert` 한 줄이다

## 3. 고친 자리

## 4. 프롬프트가 예상하지 못한 자리

**넷이 나왔다.** 프롬프트의 "고칠 절" 목록에 없었으나 그대로 두면 문서가 서로 어긋나는 자리다.

| 어디 | 무엇이 어긋나나 | 어떻게 했나 |
|---|---|---|
| 1.5절 | 제목이 "JSON이 아닌 JS 파일로 두는 이유"인데 DB로 감 | 제목과 본문을 다시 씀 |
| 3.6절 제목 | "문제 데이터 (`questions.js`)"인데 파일이 사라짐 | 제목에서 파일명을 빼고, 작성 규칙은 담는 곳이 바뀌어도 그대로 적용됨을 덧붙임 |
| 3.4절 저장 함수 계약 | `localStorage` 실패를 전제로 한 계약 | 1차의 것임을 밝히고 재정의 자리를 `IMPL-PLAN-2`로 가리킴 |
| 4.2절 3번 | `localStorage` 사용 불가 처리 | 2차에서 서버 요청 실패로 바뀜을 덧붙이고 상태 구분은 `IMPL-PLAN-2`로 넘김 |

**셋은 "고치지 말 것"에 걸려 있었다.** 3.6절 작성 규칙과 4.2절 검사 항목은 건드리지 않았고, 담는 곳이 바뀐다는 사실만 덧붙였다.

**프롬프트를 다시 쓴다면 이 넷을 미리 적었을 것이다.** 저장 위치를 바꾸면 저장을 서술한 모든 자리가 따라 움직인다는 것이 `CLAUDE.md`가 "바꾼 동작을 서술한 자리를 전부 맞춘다"로 적어 둔 것인데, 프롬프트에는 그 규칙을 넣지 않았다.

## 5. 묻는 것

**55번에 결정이 없어 PRD에 쓰지 못하고 8.3절에 모아 둔 것이 넷이다.**

- **2차 개발 단계를 몇 개로 나눌 것인가.** 인증, 데이터 이전, 서버 채점, 선생님 화면이 후보다
- **화면이 몇 개가 되는가.** 1차의 네 화면에 로그인 화면과 선생님 화면이 붙는데 선생님 화면을 몇 개로 나눌지가 없다
- **대시보드를 어디까지 만들 것인가.** 필요하다고 보았으나 항목이 확정되지 않았다
- **문제은행 확대를 어디서 멈출 것인가.** 카테고리마다 몇 문항까지인지가 없다

**하나는 결정이 있는 것으로 보고 진행했다.** 문항을 DB에 둘지 파일에 둘지인데, 55번에는 열린 항목으로 적혀 있으나 노트 5.3.5.2에 "문항을 파일이 아닌 DB에 저장하기로 5.3.3에서 결정함"이 들어와 있었고, 선생님이 화면에서 문항 생성을 요청하는 설계가 파일 방식으로는 성립하지 않는다. **판단해 진행했으므로 아니라면 되돌려야 한다.**

## 6. 55번에 반영하지 못한 것

없다. 55번의 결정 가운데 PRD에 담을 것은 모두 담았다.

다만 55번 자체가 오늘 오후의 결정 둘을 아직 담고 있지 않다. **선생님이 앱 화면에서만 작업하고 개발 도구를 쓰지 않는다는 것**과 **선생님이 문항을 직접 출제하거나 등록하지 않는다는 것**이다. 이 문서와 함께 55번을 고쳤다.
