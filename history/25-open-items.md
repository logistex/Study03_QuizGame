# 열린 항목

- 작성 이유: 아래 항목들이 대화에만 있고 문서에 없었다. 앱이 강제 종료되어 대화 기록이 화면에서 사라지면서 드러났다
- 결정된 것을 적는 문서다. 진행에 따라 이 문서를 갱신한다

## 1. 노션 5.1.6.0 — 배포 후에 채운다

노션 노트에 `5.1.6.0 단계별 구현의 완성된 모습 미리보기` 제목이 만들어져 있고 **내용은 비어 있다. 6단계 배포가 끝난 뒤에 채우기로 했다.**

채울 것은 둘이다.

- 단계별 배포 주소로 가는 링크
- 각 단계를 열면 보이는 것

| 단계 | 열면 보이는 것 |
|---|---|
| 1 | 빈 화면. 문제 40개와 검사 함수뿐이라 콘솔에 `validateData()`를 쳐야 결과가 보인다 |
| 2 | 시작 화면. 이름을 넣고 카드를 눌러도 판이 시작되지 않는다(`startGame`이 스텁) |
| 3 | 10문제를 끝까지 풀 수 있다. 결과 화면은 빈 껍데기다 |
| 4 | 점수, 정답률, 순위 진입, 순위표까지 나온다 |
| 5 | 좁은 화면 보정과 에러 처리 마무리 |
| 6 | 배포본 |

### 배포 구조를 정해야 한다

계획서 6단계는 "정적 파일 넷을 그대로 올린다"만 적고 있어 **단계별 스냅숏 배포는 범위 밖이다.** 6단계 검토 요청 때 함께 올린다.

- GitHub Pages는 브랜치 하나를 루트로 서비스하므로, 단계별 주소를 만들려면 `gh-pages` 브랜치에 `/stage1` ~ `/stage4` 하위 폴더로 각 시점 파일을 복사해 올리는 방식이 가장 단순하다
- 본편은 루트에 그대로 둔다
- **여섯 단계가 같은 오리진이라 `localStorage`를 공유한다.** 3단계를 보다 4단계로 가면 앞서 쌓인 기록이 그대로 보인다. 갈라야 한다면 저장 키에 단계를 붙여야 하는데, 그것은 배포본 코드를 고치는 일이라 권하지 않는다
- **미리보기 문서에 "단계별 화면이 순위 기록을 공유한다"를 한 줄 적는다**(26번 6절). 보는 사람이 3단계에서 4단계로 넘어가며 기록이 남아 있는 것을 보고 혼란스러워하지 않게 하려는 것이다. 5.1.6.0을 채울 때 함께 넣는다

지금은 `git worktree`로 뽑아 로컬에서만 확인하고 있다(`stage1`~`stage4` 태그).

## 2. 사파리와 VoiceOver — 확인 중

- 23번 검토 뒤 검토 측이 덧붙인 항목이다. 확인 환경이 VoiceOver와 Chrome 하나뿐이라 **VoiceOver + Safari가 확인되지 않았다**
- PRD 4절이 Safari를 지원 브라우저로 명시하고, 판정 표가 "스크린리더마다 갈리면 안 읽힌다"를 담고 있으므로 짚어야 한다
- 확인할 것 하나 — **보기를 고른 뒤 판정과 해설이 둘 다 읽히는가**
- 안 읽히면 `role="status"` 경로로 가야 하고, 그때 규격 동결 판단(20번 2절의 (가), (나))이 다시 살아난다
- 사파리에서 앱이 도는 것까지는 확인됐다. 낭독 판정은 아직이다

곁가지로, VoiceOver를 끈 뒤 데스크톱 앱에 키보드 초점이 안 돌아오는 일이 크롬과 사파리 모두에서 있었다. 앱 문제가 아니라 VoiceOver와 데스크톱 앱 사이의 문제이고, 이번 작업에서 더 파지 않는다.

## 3. 순위표 하단 고정 안내 — 감추기로 정했다 (닫힘)

24번 6절에서 검토 측에 물었으나, 답을 기다리지 않고 **사람이 감추는 쪽으로 결정했다.**

- 하단 고정 안내는 "기록은 이 브라우저에만 저장되며, 브라우저 정책에 따라 사라질 수 있습니다."다
- 저장이 된다는 전제로 쓰인 문장이라, 저장이 아예 막힌 상태에서 이 문장만 남으면 사실과 반대되는 안심을 준다
- 저장 불가 안내와 이 문장이 **서로 배타적으로** 보이게 했다. 어긋나는 두 문장을 함께 두느니 하나만 남기는 편이 분명하다
- 계획서 4.5절의 "마크업에 고정으로 두고 늘 보인다" 한 줄도 함께 고쳤다

| 상태 | 저장 불가 안내 | 사라질 수 있음 안내 | 표 | 기록 지우기 |
|---|---|---|---|---|
| 정상 | 감춤 | 보임 | 보임 | 보임 |
| 쓰기만 막힘 | 보임 | 감춤 | 보임 | 보임 |
| 읽기까지 막힘 | 보임 | 감춤 | 감춤 | 감춤 |

## 4. 5단계로 넘어간 확인 항목

- 좁은 화면에서 순위표 네 열이 넘치는지. 표가 4단계에서 생겼으므로 5단계에서 함께 본다
- 강조 줄 색 대비. 3단계에서 잰 색은 다시 재지 않고 이번에 새로 생긴 색만 잰다
- **두 탭 동시 저장.** 콘솔로는 확인했으나 실제 탭 두 개로는 아직 못 해 봤다

## 5. 검토 시점

- 검토 측 권고대로 **5단계와 6단계를 묶어 한 번에 받는다.** 배포 후에만 드러나는 것(파일명 대소문자, 상대 경로)이 있어 따로 보면 두 번 오간다
