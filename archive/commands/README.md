# 커스텀 명령어 판본 보존

`.claude/commands/`의 명령어를 고치기 전 모습으로 붙들어 두는 자리다. `CLAUDE.md`를 `archive/CLAUDE-v1.md`, `CLAUDE-v2.md`로 남긴 것과 같은 방식이다.

## quiz-validate

| 판본 | 시점 | 어떻게 만들었나 |
|---|---|---|
| `quiz-validate-v1.md` | 2026-08-17 15:36 KST | 사용자 프롬프트 없이 구현 세션이 직접 작성 |

**v1을 뜬 이유** — 이 명령어를 만들 때 오간 프롬프트가 없다. 강의 노트는 요청과 결과를 짝지어 보여 주므로, 같은 요구를 프롬프트로 적어 다시 만들어 볼 필요가 있었다. 다시 만든 것과 v1이 다르면 **같은 요구를 적어도 산출물이 갈린다**는 것이 드러난다. 그 대조를 위해 고치기 전 모습을 남긴다.

**v1의 한계 두 가지** (2026-08-17 시점에 이미 알고 있던 것)

- 한 세션이 40문항을 차례로 보는 절차로 읽힌다. 같은 날 이 방식이 40분 넘게 돌고 실패했고, 4문항씩 10갈래로 나누니 3분에 끝났다. 배치 분할과 병렬 실행이 절차에 없다
- 중간 결과를 파일로 남기라는 대목이 없다. 서브에이전트는 실패해도 조용하고, 부분 결과가 회수되지 않는다

두 가지 모두 [32번 문서](../../history/32-question-source-verification-report.md) 4절에 근거가 있다. 다만 명령어를 실제로 돌려 비교하기 전에 고치면 비교가 깨지므로, 비교가 끝난 뒤에 반영한다.
