# Study03_QuizGame

> [PRD-v2.md](PRD-v2.md) 시점의 README다. 현재 문서는 [README.md](../README.md)를 볼 것.

브라우저에서 바로 실행되는 상식 퀴즈 게임이다. 이름을 입력하고 카테고리를 골라 4지선다 문제를 풀면, 답을 고르는 즉시 정답 여부와 해설이 나온다. 한 판이 끝나면 점수가 순위표에 남는다.

서버도 계정도 빌드 도구도 없다. `index.html`을 브라우저로 열면 실행되고, 순위 기록은 브라우저의 localStorage에 남는다.

## 현재 상태

**요구사항 정의까지 끝났고, 구현은 아직 시작하지 않았다.** 저장소에 있는 것은 [PRD-v2.md](PRD-v2.md)뿐이다.

PRD는 새 세션에서 한 차례 검토를 거쳤다. 검토 전 문서는 [PRD-v1.md](PRD-v1.md)로 남아 있다.

## 기능

- 4지선다 객관식 40문제 (한국사, 과학, 지리, 예술과 문화 각 10문제)
- 두 가지 플레이 모드
  - 카테고리별 도전: 고른 카테고리의 10문제. 만점 10점
  - 전체 도전: 네 카테고리 40문제. 만점 40점
- 판을 시작할 때마다 문제 순서를 섞고, 문제를 보여 줄 때마다 선택지 순서를 섞는다
- 답을 고르는 즉시 정답, 오답 표시와 해설
- 문제마다 난이도 배지 (초급, 중급, 고급)
- 최종 점수와 정답률
- 순위표 (카테고리별 상위 5명씩, 전체 도전 상위 10명)
- 다시 열어도 남아 있는 순위 기록

만점이 다른 두 모드를 한 표에 섞으면 비교가 성립하지 않으므로 순위표를 나눠 기록한다.

자세한 요구사항과 단계별 완료 기준은 [PRD-v2.md](PRD-v2.md)에 있다.

## 기술 스택

- HTML, CSS, 순수 자바스크립트
- 라이브러리와 프레임워크 없음
- 파일 구성: `index.html`, `style.css`, `script.js`, `questions.js`

문제 데이터를 JSON이 아닌 `questions.js`에 두는 데는 이유가 있다. `index.html`을 파일로 직접 열면 주소가 `file://`이 되는데, 이때 브라우저가 보안 정책으로 `fetch()` 요청을 막는다. 스크립트로 읽어 들이면 서버 없이도 문제 데이터를 불러올 수 있다.

## 실행 방법

구현이 끝나면 `index.html`을 브라우저로 열기만 하면 된다. 설치할 것도, 띄울 서버도 없다.
